# 🌤️ SkyCast – Weather App

SkyCast is a Flutter-based weather application designed to provide users with weather information through a simple and user-friendly interface.

## ✨ Features

- Weather information through an intuitive interface.
- Clean and responsive Flutter UI.
- Easy navigation.
- Weather-related visual elements.

## 🛠️ Technologies Used

- Flutter
- Dart
- HTML, CSS and JavaScript (Flutter Web)
- GitHub Pages

## 🚀 Getting Started

### Prerequisites
- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/vedavaishnavi08/skycast.git
   ```

2. Navigate to the project directory:

   ```bash
   cd skycast
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
